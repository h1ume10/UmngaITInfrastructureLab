# Evidence captions: 03 Core services

All 12 files are in this folder. Each was checked for passwords, licence keys, credential boxes, tenant names and employer data before it was added, and none was found. The MAC address in the client ipconfig capture is blurred. The host name minint-fo3m6a9 was generated by Windows Setup and is not a real computer name.

Ten captures are headline evidence and two are supporting (the IIS welcome page and the password change message).

1. 03_step01_reverse_zone_ptr_dc1.png: DNS Manager on UMNGA-DC1 with the reverse zone 20.168.192.in-addr.arpa selected. It lists the SOA and NS records and PTR records for 192.168.20.10 (UMNGA-DC1.umnga.local), 192.168.20.11 (UMNGA-SVR1.umnga.local) and 192.168.20.12 (UMNGA-CORE1.umnga.local). The VM title bar shows the snapshot "Stage 3 before reverse zone".
2. 03_step01_nslookup_ptr_dc1.png: PowerShell on DC1 running nslookup for 192.168.20.12 and 192.168.20.11, which return UMNGA-CORE1.umnga.local and UMNGA-SVR1.umnga.local. The "DNS request timed out" lines are nslookup failing to find a name for its own server address ::1, which is normal here.
3. 03_step02_dhcp_address_pool_svr1.png: the DHCP console on UMNGA-SVR1 with Scope [192.168.20.0] Umnga Staff Devices, Address Pool selected, showing 192.168.20.100 to 192.168.20.199. The IPv4 node shows its green status icon. The title bar shows the snapshot "Stage 3 before DHCP".
4. 03_step02_dhcp_scope_options_svr1.png: Scope Options of the same scope, listing 006 DNS Servers 192.168.20.10 and 015 DNS Domain Name umnga.local. There is no 003 Router option.
5. 03_step03_ipconfig_lease_tmp1.png: the command prompt in the Windows Setup environment of UMNGA-TMP1. The top of the window shows an ipconfig /all result with a blank host name, then wpeinit is run, and the second ipconfig /all shows IPv4 192.168.20.100, subnet mask 255.255.255.0, DHCP server 192.168.20.11, DNS server 192.168.20.10, DNS suffix umnga.local, and a lease from 7 November 2026 4:38:24 PM to 15 November 2026 4:38:24 PM. The Physical Address and DHCPv6 DUID values are blurred.
6. 03_step03_dhcp_lease_list_svr1.png: Address Leases on SVR1 with one lease, 192.168.20.100 for minint-fo3m6a9.umnga.local, type DHCP, expiring 2026/11/15 16:38:12.
7. 03_step04_iis_welcome_page_svr1.png (supporting): the IIS welcome page in a browser on SVR1 at localhost. The title bar shows the snapshot "Stage 3 before IIS".
8. 03_step04_umnga_page_by_name_dc1.png: a browser on DC1 at intranet.umnga.local showing the heading Umnga Local Municipality and the text "Internal ICT page. Authorised use only." The browser marks it Not secure because the page uses HTTP.
9. 03_step05_rds_overview_svr1.png: Server Manager on SVR1, Remote Desktop Services, Overview. The Connection Broker server is UMNGA-SVR1.umnga.local. Deployment Servers lists RD Connection Broker, RD Session Host and RD Web Access, all on UMNGA-SVR1.UMNGA.LOCAL, and the collection QuickSessionCollection is in the left list. RD Gateway and RD Licensing show as not added. The title bar shows the snapshot "Stage 3 before RDS".
10. 03_step05_rds_collection_users_svr1.png: the properties of QuickSessionCollection, User Groups page, listing only UMNGA\GG_ICT.
11. 03_step05_rdp_session_dc1.png: a Remote Desktop window on DC1 whose title bar reads UMNGA-SVR1.umnga.local. PowerShell inside it shows whoami returning umnga\dubel and hostname returning UMNGA-SVR1.
12. 03_step05_rdp_password_change_error_dc1.png (supporting): the Remote Desktop Connection message "You must change your password before logging on the first time." It appeared on the first sign in as the ICT user, before the password was changed at the SVR1 console.
